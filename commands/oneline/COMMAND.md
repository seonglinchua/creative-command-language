# /oneline

**Type:** visual-language / thought-series  
**Default action:** create

A reference implementation for a minimalist recurring visual series built around one continuous line and one concise thought.

The purpose of including this command in CCL v0.1 is to demonstrate that the CCL contract can describe a creative workflow very different from Sandline.

A complete portable specification can be expanded as the workflow is formalized outside conversational state.
