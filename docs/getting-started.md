# Getting Started

1. Choose a command specification.
2. Provide it to the AI/tool that will execute the workflow.
3. Invoke the command using CCL syntax.
4. Review the output; human judgment remains authoritative.
5. Persist state in a registry when continuity matters.

Example:

```text
/sandline Singapore River
/sandline --refine --more-sand
/sandline --caption
```

CCL is a convention, not a claim that every AI natively recognizes these commands.
